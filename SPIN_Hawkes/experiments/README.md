# Experiments

Run a protocol from the repository root, for example:

```bash
python -m spin_h.experiments.exp_ssgc.experiment_1
python spin_h/first_test_spinh.py
```

Experiments 1--4 cover SSGC model comparisons and sensitivity studies.
The first full SPIN-H test is available at `spin_h/first_test_spinh.py`. Results are
written below `spin_h/artifacts/figures/` when a script enables figure saving.
