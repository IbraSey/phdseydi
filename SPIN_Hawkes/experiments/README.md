# Experiments

Run a protocol from the repository root, for example:

```bash
python -m package.experiments.exp_ssgc.experiment_1
python experiments/first_test_spinh.py
```

Experiments 1--4 cover SSGC model comparisons and sensitivity studies.
The first full SPIN-H test is available at `experiments/first_test_spinh.py`. Results are
written below `package/figures/` when a script enables figure saving.
